About ShieldScope

ShieldScope is a prototype Web3 security scanner built for the DD.xyz by Webacy Startup Accelerator Grant. It integrates Webacy's Risk Engine APIs to provide real-time due diligence on wallets, smart contracts, and phishing URLs.

  • Multi-chain support: Ethereum, Base, BSC, Polygon, Arbitrum, Optimism, Solana, and more.
  • Evidence-based reports: Each scan returns risk scores, issue details, and supporting evidence.
  • Fail-closed design: Blocked state when API key is missing or requests fail — never fake passes.
API key required for live scanning: Set the WEBACITY_API_KEY environment variable on the backend. Without it, all scans return a BLOCKED status. No keys are stored in the frontend.
